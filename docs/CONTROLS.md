# Controls

Implemented scenes: mission select, battle, result. Controls marked (hw) have been confirmed by the owner on a New 3DS XL; the rest compile but are not yet confirmed.

## Mission select

| Input | Action |
| --- | --- |
| D-pad Left / Right | Previous / next mission |
| D-pad Up / Down | Back / forward 10 missions |
| L / R | Back / forward 100 missions |
| A | Start the battle |
| Select | Toggle diagnostics overlay (frame time, worst frame, free linear memory, pack size) |
| Start | Exit to the Homebrew Launcher |

## Battle

| Input | Action |
| --- | --- |
| D-pad | Move focus between the six command cards (hw) |
| L / R | Previous / next unit (hw) |
| A | Activate the focused unit; this press is the chain timing (hw) |
| X | Fire all remaining units on the same frame (convenience mode; will become a setting, off by default) (hw) |
| Y | Next living enemy target (hw) |
| B | End the turn early, once at least one unit has acted (hw) |
| Touch | Tap a card to focus and activate it (hw) |
| Start | Retreat, after an A / B confirmation |
| Select | Toggle diagnostics overlay |

## Result

A or B returns to mission select.
