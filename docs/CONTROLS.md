# Controls

Current build implements the battle shell only.

| Input | Battle (implemented) | Planned elsewhere |
| --- | --- | --- |
| D-pad | Move focus between the six command cards | Menu focus, target selection |
| Circle Pad | - | Character movement in exploration; list scrolling |
| A | Activate the focused unit (this is the chain timing press) | Confirm / interact / advance dialogue |
| B | End the turn early (only after at least one unit has acted) | Back / cancel |
| X | Fire all remaining units on the same frame (convenience mode; will be a setting, off by default) | Details / map |
| Y | Cycle enemy target | Secondary context action |
| L / R | Previous / next unit | Previous / next tab |
| ZL / ZR | - | Optional shortcuts only |
| C-Stick | - | Optional scrolling only |
| Start | Exit (dev build) | Pause / system menu |
| Select | - | Control help overlay |
| Touch | Tap a card to focus and activate it | Lists, shortcuts |

Not yet built: separate "edit command" and "activate" states (brief section 6), ability selection, confirmation dialogs, input-bleed protection across scene changes, remapping.
